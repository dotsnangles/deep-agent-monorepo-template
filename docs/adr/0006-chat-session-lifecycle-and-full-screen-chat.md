# 6. Chat Session Lifecycle & ChatGPT-style Fullscreen Chat

Date: 2026-08-15

## Status

Accepted

## Context

사용자별 대화 기록을 효과적으로 격리하고 ChatGPT, Claude와 유사한 현대적인 대화 인터페이스를 제공하기 위해 세션의 생성 주기(Lifecycle) 및 UI 레이아웃 정책을 결정해야 했습니다.

이전에는 컴포넌트 마운트 시 무조건 세션을 생성하여 빈 세션이 DB에 누적되고, 우측 사이드바 챗 위젯에 갇혀 있어 몰입감 있는 대화 경험이 어려웠습니다.

## Decision

1. **지연 생성 (Lazy Session Creation)**:
   - 새 대화 버튼 클릭 시 클라이언트에만 Draft 세션 ID를 할당하고 DB에는 아무것도 저장하지 않습니다.
   - 첫 번째 사용자 메시지가 서버로 전송되는 시점에만 `chat_session` 레코드를 생성합니다.
2. **풀스크린 하이브리드 대화 인터페이스**:
   - 루트 경로(`/`)는 ChatGPT/Claude처럼 중앙 대화 피드와 하단 고정 프롬프트 입력창을 갖춘 몰입형 풀스크린 대화창으로 구성합니다.
   - `/dashboard` 등 별도 메뉴에서는 메트릭 및 시스템 대시보드를 유지합니다.
3. **지능형 세션 제목 생성**:
   - 첫 메시지 발송 시 앞부분 텍스트로 즉각 표시하고, 첫 턴 완료 시 요약 제목으로 업데이트합니다.

## Consequences

- 불필요한 빈 세션 저장이 원천 차단됩니다.
- 모바일 및 데스크톱 환경 모두에서 ChatGPT와 유사한 직관적이고 쾌적한 풀스크린 대화 경험을 제공합니다.
